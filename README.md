# dsh-maze

Maze 是 [DeepSeek Harness](https://github.com/) (dsh) 的常驻个人助手插件：设置页里的
**迷宫模块中心**，加右下角一位名叫 **Dolores** 的接待员——每座迷宫的中心，
都住着一位醒来的接待员。

当前模块：**提醒**（模型调用条件提醒 + cron 定时提醒）、**个性化**
（应用背景图 / 透明度 / 接待员名册）与**小记**（多机共享速记 → 任务，存储层 Vikunja）。框架按模块扩展，新模块各占设置页一个 Tab。

纯 UI 插件：不向模型上下文注入任何内容。

## 安装

```sh
dsh plugin --profile <profile> add file:/path/to/dsh-maze
```

desktop profile 由 Electron 应用管理，装完重启应用生效。

**更新**：`file:` 依赖是复制不是软链，且 pnpm 见已装会跳过——改完源码先删再装：

```sh
rm -rf ~/.dsh/profiles/<profile>/node_modules/dsh-maze
dsh plugin --profile <profile> add file:/path/to/dsh-maze
```

新 profile 开箱即用：插件自带出厂背景图、透明度偏好与五位出厂接待员
（Dolores / Maeve / Bernard / Teddy / William，各带头像与 S1-S4 原剧台词库）。
用户数据一旦存在（`data/dsh-maze/appearance.json`）则以用户文件为准。

## 使用

### 提醒（模型额度场景）

一条规则 = 触发源 × 条件 × 频控 × 文案。例：工作日 14–18 点用 glm 系模型时提醒
额度消耗（默认规则 `glm-peak-hours` 即此）。

- **触发源**：`model-call`（每次模型调用时评估）或 `cron`（5 字段标准表达式）。
- **条件**（model-call）：模型匹配 `modelPattern`（正则，i 标志，对
  `provider/model` 复合串测试；留空=全部，排除用负向断言 `^(?!.*glm)`=非智谱）、
  生效时段 `startHour/endHour`（支持跨午夜环绕）、星期限定 `daysOfWeek`（如工作日）。
- **频控**：每日上限 `maxPerDay` + 冷却 `cooldownMinutes`。
- **文案**：`{model}` `{provider}` 占位替换。
- 编辑器带 cron 常用预设与**预览效果**（服务端按草稿渲染并判断会不会命中，
  纯预览不占频控额度）；cron 规则预览下次触发时间。

提醒到达：右下角悬浮球高亮并弹气泡（吐字渐显），可「知道了」或「今日不再提醒」。
规则增删改、启停、处置历史都在设置页「提醒」Tab。

### 个性化

- **背景图片**：作用于整个应用界面；大图自动压缩（缩边 + WebP 重编码）。
- **背景透明度**：控制背景图之上的主题色纱层，100%=纯图，5%≈近实心；
  弹层与菜单保持不透明以保证设置页等浮层可读。
- **聊天框透明度**：独立调节会话内容卡片（气泡 / 输入卡 / 代码块 / 工具摘要），
  与背景纱互不牵连。
- 浅色 / 深色主题自动适配；改动实时预览，保存落盘原子写。

### 接待员

- **名册**（≤8 位）：每位 = 名字 + 头像 + 专属语录 + 启用开关。**随机觉醒**开启时
  每个浏览器会话随机一位（会话内稳定）；关闭则用指定接待员。全停用时回落内置兜底形象。
- **头像存档池**：上传过的头像自动入池（≤12 张），编辑时点击取用，换形象不用重新找图。
- **语录**：按三组分组（日常/收束/失灵，≤24 句/组，单句 ≤200 字符）——五种日常
  神态（待机/眺望/沉思/执行/审阅）共用一个大池保证随机性，收束/失灵各有专属池
  保住结果时刻的戏剧对比；清空一组=该组沉默；旧七神态配置自动迁移（五组并入
  日常，一句不丢）；
  分组默认收起防误改，删除单句两步确认。
- **状态**：显示/隐藏、固定位置（也可右键悬浮球：固定 / 隐藏）；隐藏后提醒气泡
  照常工作。悬浮球可拖拽，位置每设备记忆。
- **叙事镜像**：接待员看得见会话走向——宿主把模型调用与会话事件投影为七种神态，
  悬浮球随神态换演出（呼吸 / 摇曳 / 微浮+迷宫环 / 机芯律动 / 侧倾 / 小跳✦ /
  错帧⚠），并按概率低语一句台词；独处久了会自语。提醒永远优先，绝不插话。
  神态按会话分桶、悬浮球跟随当前会话：多会话并行时各看各的，不再互相串台。

### 小记（多机共享）

速记随手丢进共享收件箱，任何一台机器把它领走变成自己的任务——存储层是
自部署的 [Vikunja](https://vikunja.io)，体验层在设置页「小记」Tab：

- **速记**：一段文本即一条小记（首行作标题，⌘/Ctrl+↵ 快记）。
- **转任务**：给小记指定机器名（= Vikunja 用户名），它就从收件箱消失，
  出现在那台机器的「本机任务」里。
- **本机任务**：分配给本机机器名的任务列在这里，可**开工**（标记进行中）/
  **完成**。
- **删除**：小记/任务卡上均有删除（两步确认防误触）；删除是软删除进 Vikunja
  回收站，误删可在网页端回收站页恢复。
- **生命周期**：小记（未分配）→ 任务（已分配未完成）→ 进行中（start_date
  非空）→ 完成（done，可带摘要评论）→ 删除（回收站，网页可恢复）。全部落
  Vikunja，手机/网页端也能看。
- **机器名自动识别**：连接成功后按 token 身份自动回填（机器名=Vikunja 用户名，
  任务认领键，手误自动纠正），配置时留空即可。
- **Inbox 容错**：多同名 Inbox（Vikunja 会为首次密码登录的用户配发私人副本）
  确定性取 id 最小=共享池；钉死的 id 失效（项目被删/进回收站）自动重解析自愈。

**首次搭建**（本地 Docker，见 `dev/vikunja/`）：

```sh
cd dev/vikunja
node bootstrap.mjs [机器用户名 …]   # 默认 mac-mini：起容器、建用户/token/Inbox
node route-smoke.mjs                # 活体路由冒烟：假 ctx 驱动 apply()，速记→转任务→开工→完成→删除全链路
# 渲染层冒烟（repo 根另起终端: python3 -m http.server 8124 --directory <repo 根>）：
node dev/ui-preview/smoke.mjs       # jsdom 驱动真实 client.js：小记 Tab 全交互断言
# 目检：浏览器开 http://127.0.0.1:8124/dsh-maze/dev/ui-preview/（假宿主页）
```

然后在设置页「小记」填 `http://localhost:3456` 与 `connection.json`
里的 token（机器名留空自动回填），保存即连。多机接入：每台机器建自己的
Vikunja 用户（或重复跑 bootstrap 指定新机器名），token 各自持有；bootstrap
会顺手删掉登录配发的私人 Inbox 副本（避免与共享池同名混淆）。

**云端部署**（现役实例：阿里云 aliyun-ubuntu，端口只绑 tailscale0，公网零暴露）：
服务器自持 compose，与本地版的差异仅两点——`ports` 改绑 `<tailnet IP>:3456:3456`；
bootstrap 建完号后把 `VIKUNJA_SERVICE_ENABLEREGISTRATION` 改 `"false"` 重建。
Mac 侧切云端只需 `VIKUNJA_BASE=http://<tailnet IP>:3456 node dev/vikunja/bootstrap.mjs`
重建 connection.json。
